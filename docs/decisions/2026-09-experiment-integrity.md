# 実験の失敗を集計から隠さない

旧ランナーは例外をログに出して測定値を配列から省いていたため、手法ごとに異なる試行集合の平均になった。
SAVE_TRIALS=0でも木のログを蓄積していた。

失敗・非有限値は同じ試行位置のnullと失敗レコードに残す。平均は全試行成功時だけ出し、成功数・失敗数を保存する。
CLIは欠測条件の平均順位を出さず、勝ち数とtopは全手法成功の試行だけを対象として除外件数を表示する。
実験コマンドは診断結果を保存した上で終了コード1。図作成は欠測や件数不足を拒否する。

木のログは明示的に保存する場合だけ保持する。既定では巨大ログを生成しない。
乱数は関数引数で渡す。バッチは木用と手法用の独立ストリームと従来の消費順を維持し、CLIは試行・手法ごとの導出seedを維持する。
provenanceと実効設定を保存する。未コミット実行はdirty=trueで、採用結果はコミット後に再取得する。

実装: [runner](../../experiments/lib/runner.js)、[provenance](../../experiments/lib/provenance.js)。
