# リポジトリを実装と検証に絞る

このリポジトリは公開されており、目的は開発にある。発表資料や提出前の準備文書を置くと、
確定していない計画まで公開され、コードより更新の遅い文書も増える。

本文・図・発表原稿・投稿計画・論文との対応表はリポジトリの外で管理し、`/docs/paper/` を Git 対象外にした。
データ候補の調査メモと集計スクリプトも、実装に必要ないため外へ移した。これらは未pushの履歴からも除いた。

使っていなかった実データJSON 10本を削除した。`docs/data/index.md` にあった「出典不明のJSONは削除しない」方針は、
これで置き換える。push済みの履歴には残るので、必要なら取り出せる。

呼び出し元のない互換入口（`experiments/lib/*Paper.js` の4本と `run-experiments/driver.mjs`）を削除した。
2026-09 に「旧CLIパスは互換入口として残す」と決めたが、参照が残っていないためこの判断を置き換える。
